SM 업무 개요
클라이언트 요구사항 접수부터 분석·개발·테스트·배포까지 전 과정을 주도적으로 수행했습니다. 관리자 페이지 기능 개선, 사용자 UI/UX 개선, 콘텐츠 등록·수정, 반응형 레이아웃 보정 등 다수의 기능 개선 작업을 진행했습니다.
Key Highlights
🔒 인프라
SSL 인증서 교체
HTTP(80) → HTTPS(443) 리다이렉트 설정 중 Piwik이 80포트를 점유해 VirtualHost가 동작하지 않는 문제 발생. Piwik 제거 후 httpd.conf에 Redirect permanent 적용, GlobalSign 인증서 연결로 정상화했습니다.
🔍 검색
Elasticsearch 통합검색 고도화
DB LIKE 검색을 ELK 스택으로 전환. Logstash로 11개 인덱스에 데이터 적재, Java RestHighLevelClient로 멀티인덱스 검색 쿼리 구현. 자동완성(phrase_prefix)까지 적용했습니다.
🔧 운영 개선
보안 대응 및 웹 접근성 개선
비정상 트래픽 급증 탐지 후 robots.txt 크롤러 차단 규칙 정의, 가비아 DNS에서 국가 IP 대역 차단으로 서버 부하를 정상화했습니다. 아울러 WCAG 기준으로 alt 속성·ARIA 레이블·키보드 탐색 구조를 점검해 접근성 등급 향상 작업을 진행했습니다.
Problem → Solution
문제 HTTP(80) → HTTPS(443) 리다이렉트 설정 중 Piwik이 80포트를 점유하고 있어 VirtualHost *:80 설정이 동작하지 않음. HTTP 접근 시 HTTPS로 전환되지 않는 상태.
해결 Piwik 제거 → httpd.conf VirtualHost *:80에 Redirect permanent 적용 → VirtualHost *:443에 GlobalSign 인증서(crt / key / chain / CA) 연결 → JkMount로 Tomcat 연동. Apache가 SSL 종료 후 Tomcat으로 전달하는 구조로 정상 완료.
문제 콘텐츠가 여러 테이블에 분산돼 있고 DB LIKE 검색으로는 통합 조회가 불가능. 사이트 규모 확대에 따라 검색 응답 속도도 저하.
해결 Logstash로 11개 인덱스에 데이터 적재 → Java RestHighLevelClient로 멀티인덱스 검색 API 구현 → 카테고리별 태그 필드로 탭 분류. phrase_prefix 쿼리로 자동완성까지 구현.
